# REYOF // FiveM Resource Analyzer

A lightweight static analyzer for FiveM Lua resources.

## Features

- Exact duplicate function detection
- Same-name function detection
- Similar function detection
- Function relationship analysis
- FiveM event detection
- Callback detection
- Export detection
- Recursive resource scanning
- Dependency report generation
- No external Python dependencies

## Supported

- Lua
- FiveM resources
- QBCore callbacks
- ox_lib callbacks
- FiveM events
- FiveM exports

```powershell
python FiveMduptool.py .
